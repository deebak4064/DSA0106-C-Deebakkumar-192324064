2. Assessment Instructions & Rules ("How to Do & What to Do")
A. Instructions for Debugging Questions
When answering debugging questions, you must follow a structured, step-by-step analytical approach:
1. Analyze the Problem Statement: Read the expected functionality versus what the code currently does.
2. Examine the Code: Inspect each line carefully for:
• Syntax Errors: Missing tokens, invalid keywords, incorrect punctuation, misplaced semicolons.
• Semantic & Type Errors: Type incompatibilities, illegal implicit conversions, invalid reference bindings, illegal constant mutations.
• Precedence & Associativity Traps: Ambiguous compound expressions, bitwise vs. equality precedence conflicts.
• Control Flow Flaws: Unintended loop bounds, unsigned integer underflow/overflow, missing break statements in switch, invalid case labels.
• Memory Management: Mismatches between allocation (new / new[]) and deallocation (delete / delete[]).
3. Your Response for Each Question Must Include:
• Line Number & Error Classification: State the exact line number and categorize the defect (e.g., Compilation Error, Runtime Bug, Undefined Behavior, or Logic Defect).
• Root Cause Explanation: Explain why the compiler rejects the line or why the CPU generates invalid results, referencing specific C++ rules.
• Corrected Code: Provide the complete, compilable replacement code snippet.
• Dry-Run & Predicted Output: Provide the exact output generated by the corrected program.
B. Instructions for Pseudo-Code Writing Questions
When formulating pseudo-code, adhere to standard algorithmic and OOP conventions:
1. Algorithmic Structure:
• Use uppercase keywords for control structures: BEGIN, END, IF, THEN, ELSE, ENDIF, WHILE, DO, ENDWHILE, FOR, TO, STEP, ENDFOR.
• For Object-Oriented designs, define clear structural blocks: CLASS <ClassName>, PRIVATE:, PUBLIC:, CONSTRUCTOR, METHOD, ENDCLASS.
2. Variable Clarity:
• Explicitly declare variable names and types (INTEGER, REAL, BOOLEAN, STRING, ARRAY).
3. Your Response for Each Question Must Include:
• Design Overview: Brief bullet-point explanation of your chosen algorithm and OOP abstractions.
• Structured Pseudo-Code: Complete, cleanly indented pseudo-code without shortcuts or language-specific idioms.
• Trace Table / Dry Run: A structured table verifying the execution of your pseudo-code against the provided sample input.

// Line 7: Intended to check if num is odd AND greater than 10

std::cout << "Valid Odd Number: " << (int)num << std::endl;
} else {
std::cout << "Condition Failed for: " << (int)num << std::endl;
}

// Line 14: Intended to decrement from 3 down to 0 inclusive

}

3. Provide the corrected, robust C++ code snippet.
4. Show the dry run and exact console output of the corrected code.

std::cout << "Local Rate: " << taxRate << std::endl;

// Line 11: Developer attempts to use the global tax rate

{
int taxRate = 12; // Nested local variable shadowing

Student Tasks

4. Provide the expected console output.

Question 4: Optimized Prime Factorization & Divisor Engine
Topic: Control Structures (Iteration: for/while, Jump: break, continue, goto)
Scenario
Develop an algorithm that accepts a positive integer $N$, verifies its validity using input validation jumps, determines all proper divisors of $N$ in $O(\sqrt{N})$ time complexity, and classifies $N$ as Perfect, Abundant, or Deficient.
Functional Requirements
1. Input Validation:
• Prompt user for $N$. If $N \le 0$, display an error message and repeat using a jump/loop construct.
• Handle edge case $N = 1$ explicitly.
2. Divisor Generation:
• Loop candidate divisor $d$ from 2 up to $\lfloor\sqrt{N}\rfloor$.
• Use jump statement CONTINUE when $d$ does not divide $N$ evenly.
• When $d$ divides $N$, accumulate both $d$ and its paired divisor $(N / d)$ (avoiding double-counting when $d = \sqrt{N}$).
3. Classification:
• Sum of proper divisors (including 1):
• If $\text{Sum} == N$: Perfect Number (e.g., 6, 28).
• If $\text{Sum} > N$: Abundant Number (e.g., 12).
• If $\text{Sum} < N$: Deficient Number (e.g., 15).
Student Tasks
1. Write the structured pseudo-code for DivisorAndPrimeEngine.
2. Trace the algorithm with $N = 28$ and $N = 12$, showing values of $d$, $(N / d)$, and sumOfDivisors at each step.
